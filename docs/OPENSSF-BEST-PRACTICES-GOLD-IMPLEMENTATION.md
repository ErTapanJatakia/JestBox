## Additional Gold assessment focus

Assess each advanced criterion using evidence appropriate to the actual JestBox software:
- sustained independent review and contributor diversity where required;
- strong identity, authentication and maintainer access controls;
- rigorous tests, code coverage and security testing;
- reproducible or verifiable release build and artifact provenance;
- secure cryptographic design where project code uses cryptography;
- dependency, supply-chain and vulnerability response maturity.

Do not claim two-person review, independent release approval, broad contributor diversity, or cryptographic properties without evidence. Do not treat platform-managed APK signing as evidence that application code implements cryptography.
