# Declaración de accesibilidad de JestBox

## Nuestro compromiso

JestBox aspira a ser fácil de utilizar para personas con distintas necesidades de acceso. La accesibilidad es una labor continua de diseño, desarrollo y pruebas. Utilizamos las WCAG 2.2 nivel AA como referencia de diseño y evaluación. El gráfico es una marca de referencia; no implica que W3C o WAI haya revisado, aprobado o certificado JestBox.

## Funciones de accesibilidad

Ajustes y superpoderes permite elegir tamaños de texto del 50 % al 200 %, contraste adicional, movimiento reducido, enlaces subrayados, objetivos táctiles más grandes, mayor interlineado y contornos de foco de teclado más visibles. Tus preferencias se guardan localmente en tu dispositivo. La aplicación también ofrece diez temas de color, estructura semántica, controles etiquetados, navegación mediante teclado, foco visible, avisos dinámicos, diseño adaptable y compatibilidad con las preferencias del sistema para reducir el movimiento y forzar colores.

Los selectores de idioma y categoría permiten buscar texto y navegar con el teclado. La pantalla de inicio se puede cerrar mediante un toque o el teclado. Compartir requiere una acción expresa del usuario y utiliza la interfaz de la plataforma.

## Estado de conformidad y pruebas

Estas funciones son medidas de implementación, no una prueba de que todas las pantallas y combinaciones cumplan todos los criterios de las WCAG. No afirmamos disponer de una auditoría independiente ni de una certificación de W3C. El uso exclusivo del teclado, los avisos para lectores de pantalla, la ampliación del texto, el reajuste del contenido, el contraste, todos los temas, los seis idiomas, los diálogos y el comportamiento en Android requieren pruebas prácticas en distintos dispositivos y tecnologías de asistencia. Todo criterio no verificado o que no se cumpla debe registrarse y resolverse antes de afirmar conformidad.

## Limitaciones conocidas

- Las interfaces para compartir del navegador, del sistema operativo y de las aplicaciones receptoras dependen de sus respectivas plataformas.
- El comportamiento de las tecnologías de asistencia puede variar según el navegador, el sistema operativo, el dispositivo y el lector de pantalla.
- El paquete de Android y sus integraciones nativas requieren pruebas de accesibilidad específicas en dispositivos.

## Cómo comunicar una barrera de accesibilidad

Indica la pantalla o el control afectado, los pasos para reproducir el problema, el resultado esperado y el real, el dispositivo, el sistema operativo, el navegador y la tecnología de asistencia y su versión, cuando corresponda. No incluyas información personal sensible.
